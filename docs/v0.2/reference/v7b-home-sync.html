V7b home sync: mockups for sign-off

Signed off by claritise, 2026-09-28: the place, “Just above Settings”, and the short wording set: the row Sync Vocabulary; the popups Syncing vocabulary..., Vocabulary up to date, Synced · N words changed, Sync failed · No Wi-Fi, Sync stopped (“Wi-Fi” and “...” as the firmware’s other strings; the screens below still show the proposed wording, superseded by these). Proposed 2026-09-28. A Sync Vocabulary row on CrossPoint’s home screen that refreshes the vocabulary mirror (V7a) on demand. Each screen is rebuilt from the firmware’s drawing code with the default theme (Lyra) at 480×800 device pixels, then scaled to fit. The popups are the home screen’s existing ones (GUI.drawPopup and GUI.fillPopupProgress, today used for “Loading” while cover thumbnails are made); nothing new is drawn.

what the proposal adds (never drawn on the device) Screens

The home screen

The book is a stand-in: 夜の港町 by 青木 灯 (made up), its cover box holding the cover image the device would draw.

The result, for about 2 s

Text only, in the same popup. The home screen is redrawn under it first (drawPopup paints over what is there, so the wider progress box would otherwise show around a narrower result), then after about 2 s the home screen comes back as before, the row still selected.

What changes

  • One row, Sync Vocabulary, between File Transfer and Settings, with the WiFi icon the firmware already has. Settings moves down one row (y 530 → 602); the book tile and the other rows don’t move.
  • Tapping it (or Select on it) runs the mirror pass in the foreground: the existing popup with its bar, then one result popup. No new font, shape or icon.
  • The row is there only when Lexirise is on and a key is set. Builds without Lexirise draw today’s home screen.
  • New strings: the row and the four popups (Syncing vocabulary…, Vocabulary up to date, Vocabulary synced · N words changed, Sync failed · No WiFi, Sync stopped).
